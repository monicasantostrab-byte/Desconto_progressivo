#🛒 Sistema de Desconto Progressivo  

#📌 Sobre o projeto

É um programa que calcula o desconto progressivo de uma loja. O usuário deve colocar o valor total da compra, o sistema identifica a faixa de desconto correspondente que será aplicado no pagamento.  


💰 Regras para obter o desconto  

O desconto aplicado depende do valor total da compra:

Valor da compra	                      Desconto  
Menor que R$ 200,00	                    5%  
De R$ 200,00 até R$ 300,00	            10%  
Maior ou igual a R$ 300,00	            15%
